## 0. The operating idea (read first)

One founder (Harshdeep) runs four assets that feed each other:
- **Arihant Digital** (your ~10-yr agency) is the **engine** — it builds and markets the other three at internal cost.
- **Designomics** is the **design/print/packaging arm** — it supplies branding, gift boxes and merch to the group.
- **Aurra Hype** (streetwear) and **Loop In Events** (experiential) are the **revenue + content brands**.
- Every real result becomes an **Arihant case study** → outside clients → funds more capability. That loop is the flywheel.

**Sequence rule:** fix legal + brand + tech first (Month 1), turn it into an engine (Month 2), then scale and prove the numbers (Month 3). "Crore-scale in 3 months" is the direction; the honest 90-day goal is to **build the machine and prove a steep, documented growth curve with healthy unit economics.**

### 1.1 Business formation (legal)
| Step | What to do | Link |
|---|---|---|
| Choose structure | LLP or Private Limited (Pvt Ltd is best if you'll raise/scale). One holding entity or one per brand — decide with a CA. | — |
| Register the company | Incorporate via MCA (SPICe+). | https://www.mca.gov.in |
| Register on Startup India | DPIIT recognition = tax + tender benefits. | https://www.startupindia.gov.in |
| GST registration | Mandatory for e-commerce/marketplaces. | https://www.gst.gov.in |
| Udyam (MSME) | Free MSME registration — perks + credit. | https://udyamregistration.gov.in |
| Import-Export Code (IEC) | Only if Aurra/Designomics will export. | https://www.dgft.gov.in |
| Bank + payment | Current account + payment gateway (Razorpay). | https://razorpay.com |

### 1.2 Brand & trademark (do the Loop In fix here)
1. **Loop In Events name clash:** "Loop In Events" + loopinevents.com belong to an established Canadian planner. **Rename now** while it's cheap. Also "Aurra/Aura" is a crowded apparel name — make Aurra Hype's identity distinctive.
2. **Free trademark search** (wordmark + phonetic) before you lock any name: https://tmrsearch.ipindia.gov.in — check Class 41 (events), Class 25 (apparel), Class 35 (advertising/retail), Class 16/14 (gifting/jewellery if relevant).
3. **File trademarks** for all brand names + logos: https://ipindiaonline.gov.in/trademarkefiling (via an IP attorney; budget ₹8k–15k + govt fee per mark).
4. Secure **domains + social handles** for every brand before announcing (Namecheap: https://www.namecheap.com).

## 2. Per-brand implementation

### 2.1 Loop In Events — REBRAND, then build
**How to create:**
1. Shortlist 3–5 new names → run the IP-India search → pick a clear, trademarkable one → grab the .com/.in + handles → file the trademark.
2. Build a **lead-gen website** (portfolio, packages, "work with us" enquiry form) — Webflow or WordPress.
3. Set up a **CRM** (HubSpot free / Zoho) so every enquiry → quote → booking is tracked.
4. Turn on **local + LinkedIn lead-gen**; add an **event project/vendor management** system.
5. Role in the group: Loop In runs Aurra Hype's launches and Designomics' corporate-gifting experiences (internal revenue + case studies).
**Proof by day 90:** new brand live, 2–3 events booked, first case studies filmed.

### 2.2 Aurra Hype — streetwear D2C
**How to create:**
1. Refine identity + trademark; build a fast **Shopify** store (reviews, upsell, 1-tap UPI/COD checkout).
2. Shoot a proper **catalog + lifestyle** set; start a **reels engine** (3–5/week).
3. Turn on **Meta ads** (always-on) → add **Google Shopping/PMax** once profitable.
4. Add **email/SMS/WhatsApp** retention flows (cart recovery, post-purchase, win-back).
5. Set up **manufacturing + small-batch print (DTG/DTF)** so drops don't need huge MOQs; branded **packaging**; **Shiprocket** with RTO/COD control.
6. Expand to **Amazon + Flipkart**, then Myntra/Ajio; run a **drop calendar** with waitlists + influencer seeding.
**Proof by day 90:** ROAS ≥ ~2.5, repeat-purchase flows live, live on 2 marketplaces, a record drop.

### 2.3 Designomics India — gifting + the group's design/print arm
**How to create:**
1. Move off Wix to **Shopify** with a **custom gift-box builder**; premium product photography.
2. Build a **corporate-gifting sales motion** (outbound, catalog, quote-to-order, GST bulk invoicing) via the CRM.
3. Set up **supplier network + print-on-demand** for the long tail; **occasion automations** (birthdays/festivals).
4. Make Designomics the group's **packaging + merch** supplier (unboxing on every Aurra/Loop In order).
5. Later: Meesho + Amazon gifting + a Blinkit/Zepto pilot on high-margin SKUs.
**Proof by day 90:** new store live, 5+ corporate deals in pipeline, packaging shipping on every order.

### 2.4 Arihant Digital — the engine, productised
**How to create:**
1. Deliver web + ads + SEO/GEO + automation + analytics to the three brands at cost.
2. **Package offers** ("AI-native growth", "store build + launch", "automation setup").
3. Turn brand wins into **case studies** with real before/after numbers.
4. Sell to D2C brands like your own (outbound + inbound + referral); move clients to **monthly retainers**.
**Proof by day 90:** offers packaged, first outside client landed off the back of your brands.

## 3. Founder Operating System (Harshdeep)

Run all four brands from **one command center**, ~an hour a day:
1. **One dashboard** — revenue, CAC, ROAS, AOV, cash, stock, leads across all brands (Looker Studio fed by n8n).
2. **8am WhatsApp digest** — yesterday's sales, spend, best sellers, low stock.
3. **Ask-your-business assistant** — question your live data in plain language (Claude + connectors).
4. **One work system** (Notion) + **AI calendar** (Motion) + **auto meeting notes** (Fathom).
5. **One-tap approvals** for creative, spend and hires; **weekly auto-scorecard** vs targets.

## 4. The 90-day roadmap (week by week)

**Weeks 1–2 — Formation.** Entities + GST + Udyam; trademark searches + filings; rebrand Loop In; domains/handles; core accounts created; CA + IP attorney engaged.

**Weeks 3–4 — Build.** Shopify stores (Aurra, Designomics) + Loop In site live; WhatsApp API + payments + analytics + n8n connected; content pod shooting; packaging ordered; Aurra store-launch amplified; Meta ads on (ROAS baseline).

**Weeks 5–6 — Engine.** Add Google/PMax; scale Aurra winners; email/SMS/WhatsApp flows; deploy first automations (cart recovery, order updates, comment-to-DM, daily digest); Designomics corporate outbound starts.

**Weeks 7–8 — Channels.** Amazon + Flipkart live for Aurra; Loop In lead-gen + CRM + first events booked; loyalty/referral + UGC pipeline; Founder OS command center live.

**Weeks 9–10 — Scale.** Aurra drop calendar + influencer seeding + scaled budgets; Designomics quick-commerce/POD pilot + festive push; pop-ups/PR.

**Weeks 11–12 — Prove.** SOPs + first hires + dashboards; full unit-economics review; Arihant productised and pitching; build the growth-curve deck from real numbers.

## 5. Core workflows (the machine)

1. **New product → repeat customer:** add product → AI images + copy → reel + ad → live on store + marketplaces → WhatsApp broadcast → enquiry → sale → review + retention.
2. **Lead → booked event/corporate deal:** enquiry (form/DM/ad) → auto-logged in CRM + instant reply + booking link → quote → delivery → feedback + testimonial + upsell.
3. **Brand win → outside client:** result → auto KPI report → Arihant case study → outbound/inbound → retainer.

## 6. KPIs & guardrails

**Track per brand on one dashboard:** revenue + growth curve · ROAS & CAC (falling) · AOV & contribution margin (true profit after COGS/ads/RTO) · repeat rate & LTV · RTO rate (falling) · pipeline (events booked, corporate deals, Arihant clients).

**Watch:** the Loop In name/trademark fix (Month 1, non-negotiable) · founder over-extension (lean on automations + hires) · apparel RTO/COD losses · quick-commerce margins (pilot only, high-margin SKUs) · keep ad spend and subscriptions separate from build costs.
